Question 1 — TM1,1 in a rectangular waveguide
For the waveguide of Jackson Fig 8.5 (a hollow rectangular pipe, cross-section a × b, filled with μ, ε), derive the fields of the TM1,1 mode and calculate its total power flow ⟨P⟩.
ANSWER
Fields (all × e i(kz−ωt)):
Ez = E0 sin(πxa) sin(πyb)
Ex = ikγ2 πaE0 cos πxa sin πyb,    Ey = ikγ2 πbE0 sin πxa cos πyb
Hx = − iεωγ2 πbE0 sin πxa cos πyb,    Hy = + iεωγ2 πaE0 cos πxa sin πyb,   Hz = 0
γ2 = π2(1/a2 + 1/b2) = μεωλ2,    k = √μεω2 − γ2
Power:
⟨P⟩ = εωk ab E028γ2 = 12√με ω2ωλ2 (1 − ωλ2ω2)1/2  εE02  ab4
Flow: solve the 2D equation for Ez → the walls fix the allowed π/a, π/b → set m = n = 1 → get Et and Ht from Ez → integrate the Poynting vector.
2
Step 0  —  Where everything starts
The only inputs are Maxwell’s two curl equations, with every field carrying e i(kz−ωt):
∇×E = iωμH,     ∇×H = −iωεE
Because the z-dependence is e ikz, every ∂/∂z becomes ik. So split the del operator, and split the fields into transverse + z parts:
∇ = ∇t + ikz,     E = Et + zEz,     H = Ht + zHz
TM mode means Hz = 0, Ez ≠ 0
Step 1  —  Build Et and Ht out of Ez
Put the splits into the second curl equation. With Hz = 0:
(∇t + ikz)×Ht = −iωε(Et + zEz)
Same four-way sort as above: ∇t×Ht points along z, while ikz×Ht is transverse. Keeping the transverse parts:
ik(z×Ht) = −iωεEt
Cross both sides with z, using z×(z×A) = −A for any transverse A:
Ht = ωεk (z×Et) ①
3
Step 1, continued
Now the first curl equation. Substitute both splits and multiply out:
(∇t + ikz)×(Et + zEz) = iωμ(Ht + zHz)
That is four terms on the left. Sort them by direction:
#termpoints where?
1 ∇t×Et both lie flat in the cross-section → their cross is along z
2 ∇t×(zEz) transverse
3 ikz×Et z crossed with a flat vector stays flat → transverse
4 ikz×(zEz) z×z = 0 → gone
The right side splits the same way: iωμHt is transverse, iωμzHz is along z. A transverse vector can never equal a z-vector, so the one equation breaks into two independent ones:
transverse:  ∇tEz×z + ik(z×Et) = iωμHt terms 2 + 3 — the one we want
z:  ∇t×Et = iωμzHz term 1 — not needed here
Term 2 rewritten. The product rule for curl is ∇×(fA) = (∇f)×A + f(∇×A). Here A = z is a constant vector, so ∇×z = 0 and only the first piece survives:  ∇t×(zEz) = ∇tEz×z.
Substitute ① on the right:
∇tEz×z = i[ ω2μεk − k] (z×Et) = iγ2k (z×Et) γ2 ≡ μεω2 − k2
Write the left side as −z×∇tEz, then cross both sides with z again:
∇tEz = −i γ2k Et   ⇒   Et = ikγ2 ∇tEz 1/(−i) = i
And back into ①:
Ht = iωεγ2 (z×∇tEz) matches Lec 10, s17
This is the key result. Both transverse fields are now just derivatives of the single scalar Ez. Find Ez and the mode is finished.
4
Step 2  —  The equation Ez obeys
Every Cartesian field component satisfies the wave equation ∇2Ez + μεω2Ez = 0. Split the Laplacian, remembering ∂2/∂z2 → (ik)2 = −k2:
∇2 = ∇t2 + ∂2∂z2 = ∇t2 − k2
⇒  ∇t2Ez + (μεω2 − k2)Ez = 0   ⇒   ∇t2Ez + γ2Ez = 0
The wall runs parallel to z, so Ez is a tangential component there. On a perfect conductor tangential E vanishes:
Ez = 0 on all four walls
Step 3  —  Separate the variables
The cross-section is a rectangle, so try Ez = X(x)Y(y):
X″Y + XY″ + γ2XY = 0 ∇t2 = ∂2/∂x2 + ∂2/∂y2
Divide through by XY:
X″X + Y″Y + γ2 = 0
The first term depends only on x, the second only on y, and they add to a constant. The only way that can hold for all x and y is if each is separately constant:
X″X = −kx2,    Y″Y = −ky2,     kx2 + ky2 = γ2
Each is simple harmonic motion, so
X = A cos kxx + B sin kxx and the same for Y
5
Question 1, continued
Step 4  —  The walls kill the cosines and quantise the sines
At x = 0: cos(0) = 1 but sin(0) = 0, so Ez = 0 forces A = 0 — only the sine survives.
At x = a: now we need sin kxa = 0, and a sine vanishes only at whole multiples of π:
kxa = mπ   ⇒   kx = mπ/a,    m = 1, 2, 3, …
Identical argument in y:
ky = nπ/b,     γ2 = (mπa)2 + (nπb)2 = μεωλ2, Lec 12 s15
Why m and n both start at 1. If m = 0 then sin(0·πx/a) = 0 everywhere, so Ez ≡ 0 and by Step 1 every other component dies too. So TM1,0, TM0,1, TM0,0 do not exist, and the lowest TM mode is TM1,1. (TE uses cosines instead, so TE1,0 survives — that is his worked case.)
6
Step 5  —  Set m = n = 1 and write every component
Ez = E0 sin πxa sin πyb e i(kz−ωt),     γ2 = π2 (1a2 + 1b2)
Take the transverse gradient — the only differentiation in the whole problem:
∇tEz = πaE0 cos πxa sin πyb x  +  πbE0 sin πxa cos πyb y
Now just feed that into the two Step 1 formulas. For Et, multiply by ik/γ2:
Ex = ikπaγ2 E0 cosπxa sin πyb,     Ey = ikπbγ2 E0 sinπxa cos πyb
For Ht, multiply by iωε/γ2 and apply z×. Since z×x = y and z×y = −x, that swaps the components and flips one sign:
Hx = − iωεπbγ2 E0 sinπxa cos πyb,     Hy = + iωεπaγ2 E0 cosπxa sin πyb
Hz = 0 by definition of TM
Wall check. At x = 0 and x = a the tangential components are Ey and Ez, and both carry sin(πx/a) → 0 ✓. At y = 0 and y = b they are Ex and Ez, both carrying sin(πy/b) → 0 ✓.
7
Step 6  —  The Poynting vector, derived
Write ψ ≡ Ez from here on, to keep it short.
⟨S⟩ = 12 Re(E×H*),     E = Et + zψ
The piece zψ × Ht* is transverse (ẑ crossed with a transverse vector gives a transverse vector), so it has no z-component and cannot carry power along the guide. Only one term survives:
⟨Sz⟩ = 12 Re(Et×Ht*)·z
Put in the Step 1 forms:
Et×Ht* = ikγ2∇tψ × [ iωεγ2 (z×∇tψ) ]*
The conjugate flips the sign of i, so (i)(−i) = +1 and the prefactors multiply to a real positive number:
= kωεγ4 ∇tψ × (z×∇tψ*)
Now use the triple-product identity A×(B×C) = B(A·C) − C(A·B), with A = ∇tψ, B = z, C = ∇tψ*:
∇tψ×(z×∇tψ*) = z(∇tψ·∇tψ*) − ∇tψ*(∇tψ·z)
The second term is zero: ∇tψ lies in the cross-section, so it is perpendicular to z. What is left is
= z |∇tψ|2
⇒  ⟨Sz⟩ = ωk2γ4 ε |∇tψ|2
For a TE mode the same algebra runs with ψ = Hz and gives μ in place of ε. He writes the two together as a brace {ε, μ}.
8
Step 7  —  Integrate — Green’s first identity
⟨P⟩ = ∫A⟨Sz⟩ da = ωk2γ4ε ∫A (∇tψ)*·(∇tψ) da
That integral is done with Green’s first identity, which trades a squared gradient for a boundary term plus a Laplacian:
∫A(∇tψ)*·(∇tψ) da = ∮Sψ* ∂ψ∂ndL  −  ∫Aψ*∇t2ψ da
Both pieces now collapse:
1 the boundary integral is zero, because ψ = 0 on the wall (TM) — or ∂ψ/∂n = 0 (TE). This is what the wall condition was for.
2 ∇t2ψ = −γ2ψ, straight from Step 2.
⇒  ∫|∇tψ|2 da = γ2∫ψ*ψ da one γ2 comes out and cancels
⟨P⟩ = ωk2γ2ε ∫Aψ*ψ da
Finally put k = √με√ω2−ωλ2 and γ2 = μεωλ2:
⟨P⟩ = 12√με (ωωλ)2 (1 − ωλ2ω2)1/2  ε ∫ψ*ψ da
General result — true for any cross-section and any mode. Only the last integral knows the shape of the pipe.
Step 8  —  The one integral that is left
Put in ψ = Ez. The x and y integrals separate, and a squared sine over a whole number of half-periods averages to ½:
∫ψ*ψ da = E02 ∫0asin2 πxadx ∫0bsin2 πybdy = E02 a2 b2 = E02ab4
ANSWER — power flow
⟨P⟩ = 12√με (ωωλ)2 (1 − ωλ2ω2)1/2  εE02 ab4
Equivalently ⟨P⟩ = εωk ab E02 / 8γ2.
Against his TE1,0: there ψ = H0cos(πx/a), the brace picks μ, and ∫ψ*ψ da = H02(ab/2) — the n = 0 direction gives b, not b/2, because cos2(0) = 1 all the way across. That is the {ab/4 ; ab/2} brace on Lec 12, s16. Our m = n = 1 is the ab/4 branch.

Question 2 — Jackson 8.2(a)
A transmission line of two concentric metal cylinders (conductivity σ, skin depth δ), inner radius a, outer radius b, filled with a lossless dielectric (μ, ε), carrying a TEM mode. Show that the time-averaged power flow along the line is P = √μ/ε πa2|H0|2ln(b/a), where H0 is the peak azimuthal magnetic field at the surface of the inner conductor.
ANSWER
P = √μ/ε πa2 |H0|2 ln (ba)
Flow: impose Ez = Hz = 0 on Maxwell → the transverse field turns out to be an electrostatic one → solve it for two concentric circles → integrate the Poynting vector.
Step 1  —  What TEM forces
TEM means Ez = 0 and Hz = 0. Feed that into the same split Maxwell equations used in Question 1.
Take the z-components first. From ∇×E = iωμH, and from ∇·E = 0 (no free charge):
∇t×Et = iωμHz = 0   ⇒   ∇t×Et = 0
∇t·Et + ikEz = 0   ⇒   ∇t·Et = 0
Curl-free and divergence-free in two dimensions — those are exactly the conditions of a 2D electrostatics problem, even though this is a travelling wave.
A curl-free field is a gradient, and then zero divergence makes it harmonic:
Et = −∇tφ,     ∇t2φ = 0 cf. Lec 10, s13–15
10
Question 2, continued
Now the transverse parts. Each curl equation gives Ht in terms of Et:
ik(z×Et) = iωμHt  ⇒  Ht = kωμ(z×Et) ①
ik(z×Ht) = −iωεEt  ⇒  Ht = ωεk(z×Et) ②
① and ② must agree, which fixes k:
kωμ = ωεk  ⇒  k2 = μεω2  ⇒  k = ω√με so γ2 = μεω2 − k2 = 0 — TEM has no cutoff
Putting that k back into ② gives the ratio of the two fields:
Ht = √ε/μ(z×Et) = 1Z(z×Et),     Z ≡ √μ/ε
Step 2  —  Solve it for two concentric circles
Each conductor is an equipotential, and the two are concentric, so φ can depend only on ρ. In polar coordinates Laplace’s equation reads
1ρ ddρ (ρdφdρ) = 0  ⇒  ρdφdρ = constant  ⇒  φ = A ln ρ + B
Eρ = −dφdρ = −Aρ everything ∝ 1/ρ, like the field of a line charge
From Step 1, Ht = (1/Z)(z×Et), and z×ρ = φ, so H is azimuthal with Hφ = Eρ/Z. Writing H0 for its value at ρ = a, as the question does:
Hφ = H0aρ,     Eρ = √μ/ε H0aρ
Step 3  —  The Poynting vector
E is radial and H azimuthal, and ρ×φ = z, so the flow is straight along the line:
⟨Sz⟩ = 12 Re(EρHφ*) = 12 √μ/ε |H0|2 a2ρ2
11
Question 2, continued
Step 4  —  Integrate over the annulus
The dielectric fills a ≤ ρ ≤ b. A ring of radius ρ has area 2πρ dρ:
P = ∫ab 12 √μ/ε |H0|2 a2ρ2  2πρ dρ
The ρ2 downstairs cancels one ρ upstairs, leaving dρ/ρ:
= π√μ/ε |H0|2a2 ∫ab dρρ
∫ab dρρ = ln ρ |ab = ln b − ln a = ln (ba)
ANSWER — 8.2(a)
P = √μ/ε πa2 |H0|2 ln (ba)  ✓
The ln(b/a) is just ∫dρ/ρ — nothing deeper. It is the signature of a 1/ρ field, and it shows up again in the impedance and inductance of the same line.
