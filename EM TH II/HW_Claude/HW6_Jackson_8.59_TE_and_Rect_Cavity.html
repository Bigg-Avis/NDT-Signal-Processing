Question 1 — Jackson Eq. 8.59 for TE modes
Show that for a TE mode the power lost per unit length of guide is −dP/dz = (1/2σδ)(ω/ωλ)2 ∮C[ (1/μεωλ2)(1 − ωλ2/ω2) |n×∇tψ|2 + (ωλ2/ω2)|ψ|2 ] dl.
ANSWER
−dPdz = 12σδ (ωωλ)2 ∮C [ 1μεωλ2 (1 − ωλ2ω2) |n×∇tψ|2 + ωλ2ω2 |ψ|2 ]dl
Flow: start from the wall-loss formula → work out n×H on the wall, which splits into two perpendicular pieces → square it → rewrite the prefactor in terms of ω/ωλ.
Step 0  —  The starting formula
−dPdz = 12σδ ∮C|n×H|2 dl Jackson 8.58
So the whole job is to compute |n×H|2 on the wall.
Step 1  —  The TE fields
For TE, Ez = 0 and the mode is built from ψ = Hz:
H = Ht + zψ,     Ht = ikγ2 ∇tψ Lec 10, s18
wall condition:  ∂ψ∂n = 0  on C this is used in Step 3
Unlike TM, here Hz ≠ 0 at the wall — that is exactly why the TE answer has an extra |ψ|2 term that TM does not.
2
Step 2  —  Work out n×H at the wall
Set up a right-handed triad on the wall: n (outward normal, lies in the cross-section), t (along the wall), and z:
n×t = z,    t×z = n,    z×n = t   ⇒   n×z = −t
Now cross n into the two pieces of H separately:
n×H = n×Ht + ψ(n×z)
Write Ht in the wall frame as (Ht·n)n + (Ht·t)t. The n part dies under n×, leaving
n×H = (Ht·t)z  −  ψ t
The two surviving pieces point along z and t — perpendicular to each other. So when we square, there is no cross term; the magnitudes just add in quadrature.
Step 3  —  Square it
|n×H|2 = |Ht·t|2 + |ψ|2
For the first piece, put in Ht from Step 1:
Ht·t = ikγ2 (∇tψ·t) = ikγ2 ∂ψ∂t
Here is where the TE wall condition enters. Since ∂ψ/∂n = 0 on C, the gradient at the wall has no normal part — it points purely along t:
∇tψ = ∂ψ∂tt   ⇒   n×∇tψ = ∂ψ∂tz   ⇒   |∂ψ∂t| = |n×∇tψ|
⇒  |n×H|2 = k2γ4 |n×∇tψ|2 + |ψ|2
Tested numerically on all four walls of a TE10 rectangular guide — exact every time.
3
Step 4  —  Put the prefactor into Jackson’s form
We now have
−dPdz = 12σδ ∮C [ k2γ4 |n×∇tψ|2 + |ψ|2 ]dl
Jackson pulls out a factor (ω/ωλ)2, so we need to rewrite each term with that factored out. Use the two standard relations:
k2 = μεω2 − γ2,     γ2 = μεωλ2 Lec 11, s2–4
First term. Write k2 = μεω2(1 − ωλ2/ω2) and γ4 = (με)2ωλ4:
k2γ4 = μεω2(1 − ωλ2/ω2)(με)2ωλ4
Split off ω2/ωλ2 and cancel one με:
= (ωωλ)2 1μεωλ2 (1 − ωλ2ω2) ✓ Jackson’s first TE term
Second term. The |ψ|2 has coefficient 1, and
1 = (ωωλ)2 ωλ2ω2 ✓ Jackson’s second TE term — just 1 written the useful way
Both terms now carry the same (ω/ωλ)2, so it comes outside the integral:
ANSWER — Q1
−dPdz = 12σδ (ωωλ)2 ∮C [ 1μεωλ2 (1 − ωλ2ω2) |n×∇tψ|2 + ωλ2ω2 |ψ|2 ]dl  ✓
OPTIONALWhy TM looks different. For TM the wall condition is ψ = 0, so the |ψ|2 term vanishes — but ∂ψ/∂n ≠ 0, so the surviving piece is |∂ψ/∂n|2. That is Jackson’s upper line.

Question 2 — Rectangular resonant cavity, TM modes
A resonant cavity of perfect conductor has a rectangular cross section with sides a and b (and length d along z). Find the general solution for TM modes, and the lowest resonant frequency.
ANSWER
Ez = E0 sin(mπxa)sin(nπyb)cos(pπzd),    Hz = 0
ωmnp = 1√με √ (mπa)2 + (nπb)2 + (pπd)2   m, n = 1, 2, 3…   p = 0, 1, 2…
lowest = TM110:   ω110 = π√με √ 1a2 + 1b2
Flow: a cavity is a waveguide with two end caps bolted on → so solve the waveguide first (that gives the x, y shape) → then the wave cannot escape, it bounces, so put both directions ±z in and make the end caps happy (that gives the z shape) → now all three directions are quantised, and that fixes ω.
Step 0  —  What we start from
Source-free region inside, time dependence e−iωt:
∇×E = iωμH,     ∇×H = −iωεE,     ∇·E = 0,     ∇·H = 0 Lec 9, s11
The walls are perfect conductor, so on every wall (all six faces)
n×E = 0 tangential E vanishes      n·H = 0 normal H vanishes
Why these two. Inside a perfect conductor E = 0 and H = 0. Tangential E and normal H are the two combinations that must be continuous across a surface, so they are zero on our side as well. Normal E and tangential H are not continuous — they are paid for by surface charge and surface current, so they are free to be non-zero.
And TM means, by definition,
Hz = 0,     ψ ≡ Ez the one scalar everything is built from
5
Step 1  —  The waveguide piece: shape in x and y
Take the curl of the first Maxwell equation and use the second plus ∇·E = 0; every component then obeys the wave equation. Put Ez = ψ(x,y) Z(z):
(∇2 + μεω2)Ez = 0   ⇒   ∇t2ψ + γ2ψ = 0,    γ2 = μεω2 − k2 Lec 10, s17
with ∇t2 = ∂2/∂x2 + ∂2/∂y2, and k the z wavenumber. Ez is tangential to the four side walls, so
ψ = 0  at  x = 0, a  and  y = 0, b
Separate ψ = X(x)Y(y). Dividing by XY gives X″/X + Y″/Y = −γ2; one term depends only on x, the other only on y, so each must be its own constant:
X″ = −kx2X,    Y″ = −ky2Y,    kx2 + ky2 = γ2
X is a sine or a cosine. X(0) = 0 rules out the cosine, so X = sin(kxx); then X(a) = 0 forces kxa = mπ. Identically for Y:
ψ = E0 sin(mπxa)sin(nπyb),     γ2 = (mπa)2 + (nπb)2
m = 0 or n = 0 kills ψ completely (sin 0 = 0), so m, n ≥ 1 already at this step.
Step 2  —  The other components, in terms of ψ
For one travelling wave, Z = eikz, Maxwell gives the TM relations
Et = ikγ2 ∇tψ,      Ht = iωεγ2 (z×∇tψ) Lec 10, s17
In a cavity the wave bounces off both end caps, so we need both directions:
Z(z) = A eikz + B e−ikz
Add the two travelling waves. Et carries a factor ik, which flips sign for the −k wave, and that signed ik times e±ikz is exactly dZ/dz. Ht carries no k at all, so it simply adds:
Et = 1γ2 ∇tψ dZdz,      Ht = iωεγ2 (z×∇tψ) Z
Line by line: Z′ = ikA eikz − ikB e−ikz, which is (ik)(A eikz) + (−ik)(B e−ikz) — the +ik of the forward wave and the −ik of the backward one. So writing dZ/dz handles both at once.
6
Step 3  —  The end caps: shape in z
On the cap at z = 0 the normal is z, so the tangential field there is Et (that is Ex and Ey). Same at z = d. So
Et = 0  at  z = 0, d   ⇒   dZdz = 0  at  z = 0, d Step 2, since ∇tψ ≠ 0
Ez is normal to the caps, so it is not forced to vanish there — which is why z comes out as a cosine and not a sine. Rewrite Z = A eikz + B e−ikz as the equivalent pair Z = C cos kz + D sin kz, and differentiate:
Z′ = −Ck sin kz + Dk cos kz
condition gives result
Z′(0) = 0Dk = 0 D = 0, so Z = C cos kz
Z′(d) = 0−Ck sin kd = 0 kd = pπ,   p = 0, 1, 2…
⇒  Z(z) = cos(pπzd),     k = pπd C absorbed into E0
p = 0 is allowed here (cos 0 = 1 survives), unlike m and n. At p = 0 we get Z′ = 0, so Et = 0: only Ez and Ht remain, both independent of z.
Step 4  —  The resonant frequency
Step 1 defined γ2 = μεω2 − k2. Solve it for ω2 and substitute both quantised results:
ω2 = 1με [γ2 + k2] = 1με [ (mπa)2 + (nπb)2 + (pπd)2 ] same form as Lec 14, s14
This is the whole difference between a guide and a cavity. In a guide you pick ω and k adjusts to it. Here the caps pin k to pπ/d, and γ is already pinned by a and b, so nothing is left free — ω can only take the discrete values below. That is what “resonant” means.
7
Step 5  —  Write out all six components
Put ψ from Step 1 and Z from Step 3 into Step 2, using ∇tψ = (∂ψ/∂x, ∂ψ/∂y, 0) and z×∇tψ = (−∂ψ/∂y, ∂ψ/∂x, 0):
ANSWER — general TM solution
Ez = E0 sin(mπx/a) sin(nπy/b) cos(pπz/d)
Ex = −(pπ/d)(mπ/a)(E0/γ2) cos(mπx/a) sin(nπy/b) sin(pπz/d)
Ey = −(pπ/d)(nπ/b)(E0/γ2) sin(mπx/a) cos(nπy/b) sin(pπz/d)
Hx = − iωε(nπ/b)(E0/γ2) sin(mπx/a) cos(nπy/b) cos(pπz/d)
Hy = + iωε(mπ/a)(E0/γ2) cos(mπx/a) sin(nπy/b) cos(pπz/d)
Hz = 0
γ2 = (mπ/a)2 + (nπ/b)2,   m, n = 1, 2, 3…,   p = 0, 1, 2…,   everything × e−iωt.
Check the six faces. On each face, only the two components lying in that face have to vanish:
face tangential E there why it is zero
x = 0, aEy, Ez both carry sin(mπx/a)
y = 0, bEx, Ez both carry sin(nπy/b)
z = 0, dEx, Ey both carry sin(pπz/d)
And n·H = 0 comes for free: Hz = 0 takes care of the two caps, Hx carries sin(mπx/a), and Hy carries sin(nπy/b).
8
Step 6  —  The lowest resonant frequency
ωmnp increases with every index, so take each index as small as it is allowed to be:
index smallest allowed reason
m1 m = 0 makes sin(mπx/a) ≡ 0 — no field at all
n1 same, sin(nπy/b) ≡ 0
p0 cos 0 = 1, so Ez and Ht survive
So the lowest mode is TM110. Put m = n = 1, p = 0 into Step 4:
ANSWER — lowest resonant frequency
ω110 = 1√με √ (πa)2 + (πb)2 = π√με √ 1a2 + 1b2
Independent of the cavity length d, because p = 0.
Same pattern as the lecture. Lec 14 s15 does the cylindrical cavity and gets ωTM010 = 2.405/(R√με) — also p = 0, also set by the cross-section alone. There the x, y shape was a Bessel function with first zero x01 = 2.405; here it is a pair of sines giving π/a and π/b. Every other step is the same.
OPTIONALNumbers, as a check. For a = 2.3 cm, b = 1.1 cm, d = 3.4 cm, μ = 1.4μ0, ε = 2.6ε0, the ordering comes out TM110 (8.11 GHz) < TM111 (8.72) < TM112 (10.2) < TM210 (10.6) — TM110 is lowest, as claimed.
