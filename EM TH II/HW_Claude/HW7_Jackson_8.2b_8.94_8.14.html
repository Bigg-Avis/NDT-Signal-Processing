Question 2 — Derive Jackson Eq. 8.94
For a cylindrical cavity of length d, in a TM mode with p ≠ 0, show that the power lost in the walls is Ploss = (ε/σδμ)[1 + (pπ/γλd)2] (1 + ξλCd/4A) ∫A|ψ|2da, where C is the circumference and A the cross-sectional area.
ANSWER
Ploss = εσδμ [1 + (pπγλd)2 ] (1 + ξλ Cd4A) ∫A|ψ|2da
Flow: the cavity has two kinds of wall — the sides and the two flat ends. Work out the loss on each separately, add them, then use one standard identity to turn everything into the single integral ∫|ψ|2da.
Step 0  —  The field in the cavity
A cavity is a waveguide with two end caps a distance d apart. The ends force a standing wave in z, so the travelling factor eikz is replaced by a cosine with k = pπ/d, p = 0, 1, 2, …
For a TM mode the magnetic field is purely transverse:
H = Ht = iεωγ2 cos(pπzd)  z×∇tψ Lec 15, s13
The wall loss formula is the same one as Question 1, now applied over the whole cavity surface:
Ploss = 12σδ ∮ |n×H|2 da Jackson 8.93
Step 1  —  Loss on the sides
On a side wall the normal n lies in the cross-section. Taking the cross product picks out the normal derivative of ψ:
|n×H|2 = ε2ω2γ4 |∂ψ∂n|2 cos2(pπzd)
The side surface is “perimeter × length”, so da = dL dz. Integrate along z first — a squared cosine over the full length averages to ½:
∫0d cos2(pπzd)dz = d2 true for p ≠ 0 — this is where p ≠ 0 is used
Psides = d4σδ ε2ω2γ4 ∮|∂ψ∂n|2dL
4
Step 2  —  Loss on the two ends
On an end cap the normal is n = ±z. Then
|n×H|2 = ε2ω2γ4 |z×(z×∇tψ)|2 = ε2ω2γ4 |∇tψ|2 z×(z×A) = −A
At the ends cos(pπz/d) is cos 0 = 1 or cos pπ = ±1, so its square is 1 either way. There are two ends, which cancels the ½ in front:
Pends = 1σδ ε2ω2γ4 ∫A|∇tψ|2da
Use Green’s first identity exactly as in HW 5 — the boundary term dies because ψ = 0 on the wall, and ∇t2ψ = −γ2ψ:
∫|∇tψ|2da = γ2∫|ψ|2da   ⇒   Pends = 1σδ ε2ω2γ2 ∫A|ψ|2da
Step 3  —  Add the two
Ploss = ε2ω2σδγ4 [ d4 ∮|∂ψ∂n|2dL  +  γ2∫A|ψ|2da ]
Step 4  —  Kill the remaining boundary integral
The one awkward piece is ∮|∂ψ/∂n|2dL. There is a standard identity for it, which simply defines the dimensionless number ξλ:
∮|∂ψ∂n|2dL = ξλ γ2 CA ∫A|ψ|2da Jackson 8.62 · Lec 15 s16
Substitute it in. Every term now carries the same ∫|ψ|2da, so it factors out:
Ploss = ε2ω2σδγ4 [ d4ξλγ2 CA + γ2] ∫|ψ|2da
One γ2 cancels:
Ploss = ε2ω2σδγ2 (1 + ξλ Cd4A) ∫A|ψ|2da = Lec 15, s16

Step 5  —  Put it in Jackson’s form
The answer above is complete, but Jackson writes the prefactor differently. The two are the same thing — here is the conversion.
In a cavity the resonance condition is
μεω2 = γλ2 + (pπd)2 transverse part + z part Lec 14, s14
So solve that for εω2 and substitute:
ε2ω2γλ2 = ε  εω2γλ2 = ε  γλ2 + (pπ/d)2μ γλ2
Split the fraction:
= εμ [1 + (pπγλd)2 ]
Checked numerically for p = 0, 1, 2, 3 — the two expressions agree to 16 digits every time.
ANSWER — Q2 (Eq. 8.94)
Ploss = εσδμ [1 + (pπγλd)2 ] (1 + ξλ Cd4A) ∫A|ψ|2da  ✓
The [1 + (pπ/γλd)2] is the standing wave in z; the (1 + ξλCd/4A) is the sides compared with the ends.

Question 3 — Jackson 8.14
An optical fibre has a graded index n(x) = n(0) sech(αx), for rays in the x–z plane. The invariant is n = n(xmax) = n(0)cos θ(0). (a) Solve the eikonal equations for x(z) and show αx = sinh−1[sinh(αxmax)sin(αz)]; sketch rays for θ(0) = π/6, π/4, π/3. (b) Find the half-period Z. Does it depend on n? (c) Show Lopt = ∫n(x)ds = n(0)Z, and comment.
ANSWER
(a)  sinh(αx) = sinh(αxmax) sin(αz)
(b)  Z = πα  —  independent of n
(c)  Lopt = n(0) Z  —  same for every ray
Flow: the ray equation gives dx/dz → separate and integrate → the substitution u = sinh(αx) turns it into a plain arcsine → then (b) and (c) are read off that one result.
Step 1  —  The ray equation for a slab
For an index that varies only with x, ray tracing gives a first integral — the quantity n is conserved along the ray:
n2 (dxdz)2 = n2 − n2 Lec 17, s5
Take the square root and separate:
dxdz = √n2 − n2n   ⇒   dz = n dx√n2 − n2
At the turning point x = xmax the ray is momentarily flat, dx/dz = 0, so n(xmax) = n — that is exactly the invariant the problem defines.

Step 2  —  Substitute u = sinh(αx)
Put in n = n0sech(αx), writing n0 = n(0). The substitution that clears the sech is u = sinh(αx), because cosh2 = 1 + sinh2:
n2 = n02cosh2(αx) = n021 + u2,     du = α cosh(αx) dx  ⇒  dx = duα√1+u2
The messy square root becomes
n2 − n2 = n02 − n2(1+u2)1 + u2
Now put both into dz. The √1+u2 factors cancel:

Step 3  —  Integrate — it is an arcsine
Pull n out of the root so it reads ∫du/√U2−u2, the standard arcsine form, where
U ≡ √n02 − n2n
z = 1α ∫du√U2 − u2 = 1α sin−1uU the problem puts z = 0 at x = 0, so the constant is zero
Invert it:
u = U sin(αz)   ⇒   sinh(αx) = U sin(αz)
Step 4  —  Recognise U
From Step 1, at the turning point n(xmax) = n, so n0sech(αxmax) = n, i.e. cosh(αxmax) = n0/n. Then
sinh(αxmax) = √cosh2 − 1 = √n02/n2 − 1 = √n02−n2n = U
ANSWER — (a)
sinh(αx) = sinh(αxmax) sin(αz)   i.e.   αx = sinh−1[ sinh(αxmax) sin(αz) ]  ✓

PART (b)  — the half-period Z
A half-period ends when the ray comes back to the axis, x = 0. From part (a) that needs sin(αz) = 0, and the first non-zero solution is αz = π:
ANSWER — (b)
Z = πα   —   it does not depend on n
α is the only quantity in it. Every ray, whatever its launch angle, returns to the axis after the same distance.

Step 1  —  Turn ds into dz

1 + (dxdz)2 = 1 + n2−n2n2 = n2n2   ⇒   ds = nndz

Step 3  —  Use the hint
Substitute t = αz (so dz = dt/α, t runs 0 → π), then fold the symmetric halves together to get 2∫0π/2. The given integral is
∫0π/2 dt1 + S2sin2t = π2√1+S2 the hint in the question

Finally, √1+S2 = cosh(αxmax) = n0/n from Step 4 of part (a). Substituting, the n cancels and one n0 cancels:
ANSWER — (c)
Lopt = π n0α = n(0) Z  ✓
Comment. Lopt contains no n, so every ray has the same optical path length per half-period, no matter what angle it was launched at. Optical path length is what sets travel time, so all rays arrive together — the pulse does not smear out. That is exactly what a multimode fibre wants, and it is why the sech profile is the ideal grading. A step-index fibre has no such property: steep rays take visibly longer, which limits how fast you can send data.
