Example 1 — TE modes in a rectangular waveguide
A hollow guide of perfect conductor has a rectangular cross section, sides a along x and b along y, filled with μ, ε. Find the TE modes, their cutoff frequencies, the lowest mode, and write out its fields. (Lec 11 s6–9.)
ANSWER
ψ = Hz = H0 cos(mπxa)cos(nπyb),    γ2mn = (mπa)2 + (nπb)2
ωmn = π√με √m2a2 + n2b2   m, n = 0, 1, 2… but not both 0   ⇒   lowest TE10:  ω10 = πa√με
Flow: TE means everything is built from Hz → solve the 2D wave equation for it → the wall condition for TE is ∂ψ/∂n = 0, which picks cosines → the box quantises m and n → cutoff is where k stops being real.
Step 1  —  What we start from
TE means Ez = 0, and the one scalar is ψ = Hz. With everything going as ei(kz−ωt):
∇t2ψ + γ2ψ = 0,    γ2 = μεω2 − k2,      ∂ψ∂n = 0 on the walls Lec 10, s18
Ht = ikγ2∇tψ,      Et = − iωμγ2 (z×∇tψ) needed in Step 5
Step 2  —  Separate x from y
Put ψ = X(x)Y(y) into the wave equation and divide by XY:
X″X + Y″Y = −γ2
The first piece depends only on x and the second only on y, yet they add to a constant. The only way is for each to be its own constant:
X″ = −kx2X,    Y″ = −ky2Y,    kx2 + ky2 = γ2
2
Example 1 — TE in a rectangular waveguide (continued)
Step 3  —  Apply the TE wall condition
On the walls x = 0 and x = a the outward normal is ±x, so ∂ψ/∂n there means ∂ψ/∂x:
X′(0) = X′(a) = 0
X is a sine or a cosine, so X′ is the other one. X′(0) = 0 kills the sine (its derivative is a cosine, which is 1 at 0), leaving X = cos(kxx). Then X′(a) = −kxsin(kxa) = 0 forces kxa = mπ. Identically for y:
ψmn = H0 cos(mπxa)cos(nπyb),    γmn2 = (mπa)2 + (nπb)2
Watch his slide here. Lec 11 s6 lists the wall conditions as ∂Hz/∂x = 0 on y = 0, b and ∂Hz/∂y = 0 on x = 0, a. Those two are swapped — the normal on x = 0, a is x, so it is ∂Hz/∂x that vanishes there. His final ψmn is right, because the cosines are symmetric in the two directions and the slip cancels.
TE gives cosines, TM gives sines. That one difference is the whole reason the two mode families have different allowed indices and different lowest modes. Keep it straight and Examples 1 and 2 are the same problem.
Step 4  —  Cutoff frequency, and which (m,n) are allowed
Solve γ2 = μεω2 − k2 for k:
k = √μεω2 − γmn2
For the wave to travel instead of die away, k must be real. That needs μεω2 ≥ γmn2, so each mode has its own threshold frequency:
ωmn = γmn√με = π√με √m2a2 + n2b2 below this the mode does not propagate
Which pairs (m,n) are real modes? Only m = n = 0 has to be thrown away, because then ψ = H0 is a constant, so ∇tψ = 0 and from Step 1 every transverse field is zero — nothing is being carried.
m, n = 0, 1, 2…   but not both zero
So with a > b the smallest ωmn is m = 1, n = 0:
TE10:   ω10 = πa√με = πacn the dominant mode; n = c√με is the index of the filling

Hx = − i (ka/π) H0 sin(πx/a)

Example 2 — TM modes in the same rectangular guide
Same guide. Now find the TM modes, their cutoff frequencies and the lowest one. (Lec 11 s10–11.)
ANSWER
ψ = Ez = E0 sin(mπxa)sin(nπyb),    m, n = 1, 2, 3…
ωmn = π√με √m2a2 + n2b2   ⇒   lowest TM11:  ω11 = π√με √1a2 + 1b2
Flow: identical to Example 1 except for one line — the wall condition. TM has ψ = 0 instead of ∂ψ/∂n = 0, and everything downstream follows from that.
Step 1  —  The only thing that changes
TM means Hz = 0 and ψ = Ez. The wave equation is the same, but Ez lies in the wall, so it is tangential and must vanish there:
∇t2ψ + γ2ψ = 0,      ψ = 0 on the walls Lec 10, s17
Et = ikγ2∇tψ,      Ht = iωεγ2 (z×∇tψ)
Step 2  —  Separate, then apply ψ = 0
The separation is word-for-word Step 2 of Example 1: X″ = −kx2X, Y″ = −ky2Y. Now X(0) = 0 rules out the cosine this time, leaving X = sin(kxx), and X(a) = 0 forces kxa = mπ:
ψmn = E0 sin(mπxa)sin(nπyb),    γmn2 = (mπa)2 + (nπb)2
Step 3  —  Allowed indices and the lowest mode
sin(0) = 0, so m = 0 or n = 0 wipes ψ out completely. Unlike TE, both indices must start at 1:
m, n = 1, 2, 3…   ⇒   TM11:  ω11 = π√με √1a2 + 1b2
The point of the pair. γ2mn and ωmn are the same formula for TE and TM. What differs is only which (m,n) survive. TE can use m = 0, TM cannot, so ωTE,lowest < ωTM,lowest always — which is the line he ends on. For a = 2.5 cm, b = 1.2 cm it is 2.31× higher.

A cylinder of perfect conductor, radius R, length d, filled with μ, ε. Find the TE fields in full, then the TM ones. (Lec 14 s3–13.)
ANSWER — TE
Hz = ψ(x,y) sin(pπzd),    Ht = pπ/dγ2 cos(pπzd)∇tψ,    Et = − iμωγ2 sin(pπzd)(z×∇tψ)

Step 0  —  Set the problem up
Inside the cavity there are no sources, so each field obeys Helmholtz:
∇2E + μεω2E = 0,     ∇2H + μεω2H = 0 time dependence e−iωt
The walls are perfect conductor, so on the whole surface S
H⊥ = 0,     E∥ = 0   on S,     S = { ρ = R  the side
z = 0, d  the two caps

Example 4 — Cylindrical resonant cavity (continued)
Step 1  —  Translate the wall conditions
“Tangential E vanishes” says different things on the side and on the caps, because what counts as tangential changes. Going through it face by face:
mode on ρ = R on z = 0, d
TM (Hz = 0) Ez = 0 Et = 0
TE (Ez = 0) ∂Hz/∂n = 0 Hz = 0  and  Et = 0
Reading the table. On the side wall Ez runs along the wall, so it is tangential and must die — that is the TM line. For TE there is no Ez, and the condition that survives is the one on Hz: n·H = 0 on the side forces Hρ = 0, and Hρ ∝ ∂Hz/∂ρ, which is why the TE side condition is a derivative. On the caps, n = z, so Hz is the normal component — hence Hz = 0 there — while Ex, Ey are the tangential ones.
Step 2  —  The six component equations
These come straight from splitting the two Maxwell curl equations into a z part and a transverse part. Nothing is assumed about the z dependence — that is why they work in a cavity and not only in a guide:
①  ∂Et∂z + iωz×Bt = ∇tEz ②  z·(∇t×Et) = iωBz
③  ∂Bt∂z − iμεωz×Et = ∇tBz ④  z·(∇t×Bt) = −iμεωEz
⑤  ∇t·Et = −∂Ez∂z ⑥  ∇t·Bt = −∂Bz∂z
with B = μH. Lec 14, s5

Example 4 (continued)
Step 3  —  TE: find Hz first
For TE we have Ez = 0, so Hz is the only z component left. It obeys Helmholtz, and from Step 1 it vanishes on both caps:
∇2Hz + ω2μεHz = 0,     Hz = 0 at z = 0, d
Separate the z direction from the cross-section:
Hz = ψ(x,y) Z(z) e−iωt   ⇒   ∇t2(ψZ) + ∂2∂z2(ψZ) + ω2με(ψZ) = 0
Divide through by ψZ:
1ψ∇t2ψ + 1Z∂2Z∂z2 + ω2με = 0,     1Z∂2Z∂z2 ≡ −k2
The middle term depends only on z while the others do not, so it must be a constant; call it −k2. Then Z″ = −k2Z with Z(0) = Z(d) = 0. The cosine cannot satisfy Z(0) = 0, so
Z = sin(pπzd),    k = pπd,    p = 1, 2, 3… p = 0 would kill Hz entirely
Step 4  —  TE: the cross-section shape
With Z fixed, what is left of Helmholtz is a 2D equation for ψ:
∇t2ψ + (ω2με − k2)ψ = 0,    γ2 ≡ ω2με − k2,    ∂ψ∂n = 0 at ρ = R
In polar coordinates the bounded solutions of this are Bessel functions:
ψ = H0 Jm(γmnρ) e±imφ the second kind Ym blows up at ρ = 0, so it is dropped
Which γ is allowed is set by the wall and is done in Example 5. Here we only need to know ψ exists and satisfies ∇t2ψ = −γ2ψ.

Step 5  —  TE: get Ht
Take ① and ③ and put Ez = 0 into them:
①  ∂Et∂z + iωz×Bt = 0   ⇒   ∂Et∂z = −iωμ z×Ht call this (a)
Now differentiate ③ with respect to z, so that ∂Et/∂z appears and (a) can be used:
μ∂2Ht∂z2 − iμεωz×∂Et∂z = μ∇t∂Hz∂z
Substitute (a). The double cross product collapses with z×(z×Ht) = −Ht, and the two i’s give i2 = −1, so the sign flips twice and the term comes out positive:
μ∂2Ht∂z2 + ω2μ2εHt = μk cos(kz) ∇tψ since ∂Hz/∂z = kψcos(kz)

(−μk2 + ω2μ2ε)Ht = μk cos(kz)∇tψ   ⇒   Ht = μkω2μ2ε − μk2 cos(kz)∇tψ
The denominator is μ(ω2με − k2) = μγ2, so the μ cancels:

The integration constant is set to zero by the cap condition Et = 0 at z = 0 — and once it is zero, the sine makes z = d work for free. Both caps are satisfied by one choice.

Flow: in a cavity the electric and magnetic energies trade places every quarter cycle, so the total is just twice the magnetic part → for TM the magnetic field is purely transverse, which makes that the easy one to integrate → the z integral gives d/2 → Green’s identity converts ∫|∇tψ|2 into ∫|ψ|2.
Step 1  —  Why ⟨U⟩ is twice the magnetic energy
Look at the TM fields from Example 4: E carries sin(pπz/d) or cos, with no i, while Ht carries an explicit i. An i is a quarter-cycle delay, so when E is at its peak H is zero and the other way round. The total energy therefore never changes — it just sloshes — and equals the peak of either one:
U = ∫μ|Ht|2 da dz   ⇒   ⟨U⟩ = ∫12μ|Ht|2 da dz Lec 15, s9
For TM, Hz = 0, so Ht is the whole magnetic field — nothing is left out.

|Ht|2 = ε2ω2γ4 cos2(pπzd) |∇tψ|2

Example 8 — Modes in a step-index circular fibre
A fibre with a core of index n1 for ρ < a and cladding n2 for ρ > a. Find the mode shapes, the condition that picks the allowed modes, and the lowest cutoff frequency. (Lec 17 s16–19.)
ANSWER
(n12γJ′mJm + n22βK′mKm) (1γJ′mJm + 1βK′mKm) = m2a2 (n12γ2 + n22β2) (1γ2 + 1β2)
lowest TE/TM cutoff:   V = n1ωa√2Δc = 2.405   ⇒   ω = 2.405 cn1a√2Δ
Flow: the index is constant inside and constant outside, so the coupling term of Example 7 lives only at the interface → solve a plain Helmholtz equation on each side → the coupling comes back as the matching condition at ρ = a, and that is the boxed equation.

Step 1  —  Where the coupling lives
Write the step profile and differentiate it. A step drops to a delta function:
n = { n1  ρ < a
n2  ρ > a   ⇒   ∇tn2 = −2n12Δ δ(ρ−a) ρ
where Δ is the usual fractional index step:
Δ = n12 − n222n12   ⇒   n12 − n22 = 2n12Δ so the jump in n2 is exactly 2n12Δ
This is the whole trick of a step-index fibre. Away from ρ = a the gradient is zero, so all the nasty terms of Example 7 vanish and we are back to ordinary Helmholtz equations. The coupling has not disappeared — it has been squeezed into a single surface, where it becomes a matching condition.
Step 2  —  Solve on each side
Inside (ρ < a). Guided light travels mostly in the core, so γ2 = n12ω2/c2 − k2 > 0 and the equation is oscillatory. Bounded at the axis ⇒ ordinary Bessel:
{Ez
Hz} = {Ae
Ah} Jm(γρ)eimφ
Outside (ρ > a). For the light to stay trapped the field must decay, so there the sign flips:
β2 = k2 − n22ω2c2 > 0   ⇒   ∇t2ψ − β2ψ = 0   ⇒   {Ez
Hz} = {Be
Bh} Km(βρ)eimφ
Km is the modified Bessel function that dies as ρ → ∞. Its partner Im grows without bound, so it is thrown away — the same reasoning that threw away Ym at the axis, just at the other end.

Step 3  —  Match at ρ = a
Four unknowns (Ae, Ah, Be, Bh) and four conditions — the tangential fields Ez, Hz, Eφ, Hφ must be continuous across the interface. That is a 4×4 homogeneous system; a non-trivial solution exists only if its determinant vanishes, and that determinant is the boxed equation:
(n12γJ′mJm + n22βK′mKm) (1γJ′mJm + 1βK′mKm) = m2a2 (n12γ2 + n22β2) (1γ2 + 1β2) Lec 17, s17
All the Bessel functions are evaluated at ρ = a.
Step 4  —  Read the equation: m = 0 against m > 0
m = 0. The right side is zero, so the left side factorises and each bracket can vanish on its own:
(n12/γ)(J′0/J0) + (n22/β)(K′0/K0) = 0 TM modes
(1/γ)(J′0/J0) + (1/β)(K′0/K0) = 0 TE modes
m > 0. The right side is non-zero, the two brackets cannot be separated, and Ez and Hz must both be present — these are the hybrid (EH and HE) modes, exactly the coupling predicted in Example 7.
Rays, in picture language. m = 0 modes are meridional rays — they zig-zag through the axis, staying in one plane. m > 0 modes are skew rays — they spiral around the axis without ever crossing it, which is why their intensity is zero at ρ = 0.

Step 5  —  Cutoff, and the number 2.405
Cutoff is the moment the mode stops being guided: the field outside stops decaying, so β → 0. Add the two definitions of γ2 and β2 from Step 2 — k2 cancels:
γ2 + β2 = (n12 − n22)ω2c2 = 2n12Δ ω2c2
At cutoff β = 0, so γ takes the whole of it. Define V ≡ γa at that point:

With β = 0 the K-terms drop out of the m = 0 conditions and both reduce to J0(V) = 0, whose first root is 2.405:
V = 2.405   ⇒   ω = 2.405 cn1a√2Δ
Two things worth keeping. (i) The hybrid HE11 mode has no cutoff — it propagates at every frequency — so a fibre with V < 2.405 carries exactly one mode. That is the definition of a single-mode fibre. (ii) n1√(2Δ) is identically √(n12 − n22), the numerical aperture, so V = NA · ωa/c.
